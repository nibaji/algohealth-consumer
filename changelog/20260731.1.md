# Release 20260731.1

- 2026-07-31: Changed Consults loading to fetch only All sessions and family-member filter options on entry. Member-specific sessions now load on demand with a list skeleton whenever a member chip is tapped, while stale responses from rapid filter changes are ignored. Changed in `app/consults/index.tsx`, `src/features/consults/useConsultSessions.ts`, and `README.md`.

Moved consult-history data loading into a feature hook and documented the member-ID source and request flow. Changed in `app/consults/index.tsx`, `src/features/consults/useConsult.ts`, `src/features/consults/useConsultSessions.ts`, `src/services/consults/consultService.ts`, and `README.md`.
